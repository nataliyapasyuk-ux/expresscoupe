# Бот «Экспресскупе»

Telegram-бот-квиз для мебельного магазина (купе/гардеробные): вход по
`t.me/ИМЯ_БОТА?start=channel`, скидка → согласие на ПД → телефон →
промокод, лид падает в рабочую группу и в Google Sheets.

## Установка

```bash
npm install
cp .env.example .env
```

Заполнить `.env`:
- `BOT_TOKEN` — токен от @BotFather
- `LEADS_CHAT_ID` — id рабочей группы (добавить бота в группу, узнать id
  можно через `@userinfobot` или лог первого апдейта)
- `SHEET_ID` — id таблицы из её URL

## Google Sheets — сервисный аккаунт

1. https://console.cloud.google.com/ → создать проект.
2. APIs & Services → Library → включить **Google Sheets API**.
3. APIs & Services → Credentials → Create credentials → **Service account**.
4. У созданного аккаунта → вкладка **Keys** → Add key → Create new key →
   **JSON**. Сохранить файл как `service-account.json` в корень проекта
   (или указать свой путь в `GOOGLE_SERVICE_ACCOUNT_FILE`).
5. Открыть саму Google-таблицу → «Настройки доступа» → выдать
   **редактору** e-mail сервисного аккаунта (из JSON-файла, поле
   `client_email`) — иначе бот не сможет писать в таблицу.

### Структура таблицы

Лист **«Лиды»** (создаётся ботом автоматически при первой записи, если
уже существует — просто дописывает строки), колонки A–G:

`Дата | Имя | Телефон | Источник | Промокод | TG username | Комментарий`

Лист **«Настройки»** (правит заказчица сама, без доступа к серверу),
две колонки — ключ/значение, начиная со строки 2:

| A | B |
|---|---|
| product | шкаф-купе |
| discount | 10% |
| promo | ДОБРО_ПОЖАЛОВАТЬ2016 |
| msg_offer | Скидка {discount} на {product}. Забрать за 20 секунд. |
| msg_ask_phone | Ваша скидка {discount} уже закреплена за вами... |
| msg_promo | Готово! Ваш промокод: {promo} — скидка {discount}... |

Плейсхолдеры `{discount}`, `{product}`, `{promo}` подставляются
автоматически. Бот перечитывает этот лист раз в 2 минуты
(`SETTINGS_REFRESH_MS`), перезапуск не нужен.

## Запуск

```bash
npm start
```

Локальная разработка (перезапуск при правке файлов):

```bash
npm run dev
```

## Деплой на bothost.ru

1. Залить проект (без `node_modules/`, `.env`, `service-account.json`)
   и выполнить `npm install` на сервере.
2. Положить `.env` и `service-account.json` рядом с кодом.
3. Запуск как обычный Node-процесс (`npm start`) под supervisor'ом
   площадки — polling, вебхук не нужен.

## Состояние

- Состояние диалога и дедуп по `telegram_id` — локальный SQLite
  (`data/bot.db`), создаётся автоматически.
- Контент и промокод — Google Sheets, лист «Настройки».
- Готовые лиды — Google Sheets, лист «Лиды» + карточка в рабочей группе
  с кнопкой «Взять в работу».
